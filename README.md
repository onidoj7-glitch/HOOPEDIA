# 🏀 Hoopedia — The Basketball Knowledge Library

Hoopedia is a simple, Wikipedia-inspired website that provides information about basketball rules, plays, strategies, positions, skills, and history. It uses a clean white layout with green accents to make basketball knowledge easy to read and explore.

## 📌 Project Overview

- **Project Name:** Hoopedia
- **Project Type:** Basketball Encyclopedia Website
- **Category:** Web Development
- **Purpose:** To provide organized and accessible basketball information.

## ✨ Features

- Home page with an introduction to basketball.
- Basketball rules and regulations.
- Plays and techniques.
- Basketball strategies.
- Basketball history.
- Player positions and skills.
- Sidebar navigation between pages.
- Simple and readable Wikipedia-inspired design.
- White background with a green color theme.
- Responsive layout for different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Explore the different basketball topics using the navigation links.
